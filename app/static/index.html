Un lien, une adresse ou un fichier vous semble suspect ? Vérifiez-le ici.

SecureShip compare ce que vous collez à des milliers d'indicateurs de menaces signalés par la communauté cyber, mis à jour chaque matin.

Un élément par ligne, 100 au maximum. Les liens « désarmés » comme hxxp://site[.]com sont acceptés.

Pas d'exemple sous la main ? Essayez :

Vos recherches ne sont ni enregistrées ni transmises à un tiers : la comparaison se fait sur le serveur de SecureShip.

Résultats

    Lire le résultat

    Signalé

    Connu comme malveillant

    L'élément figure dans une base de menaces. N'ouvrez pas le lien, ne lancez pas le fichier et prévenez votre service informatique si c'est un appareil professionnel.

    Rien trouvé

    Absent de la base

    Aucun signalement connu. Ce n'est pas une garantie : une menace toute récente peut ne pas encore être répertoriée. Restez prudent si le message vous presse ou vous demande vos identifiants.

    Non reconnu

    Format inconnu

    Ce n'est ni une adresse IP, ni un domaine, ni un lien, ni une empreinte de fichier. Vérifiez qu'il n'y a pas de faute de frappe ou d'espace en trop.

    Ce que vous pouvez vérifier

    Un lien (URL)
    Le domaine est extrait automatiquement. Copiez le lien avec un clic droit plutôt que de l'ouvrir. https://exemple.com/page
    Un nom de domaine
    Les sous-domaines d'un domaine signalé sont signalés aussi. connexion.exemple.com
    Une adresse IP
    IPv4 ou IPv6, avec ou sans numéro de port. Les adresses de réseau local sont identifiées comme privées. 203.0.113.66:443
    L'empreinte d'un fichier (hash)
    Une suite de 32, 40 ou 64 caractères qui identifie un fichier sans l'envoyer. Formats MD5, SHA-1 et SHA-256.

    Obtenir l'empreinte d'un fichier sans l'ouvrir

    Le fichier ne quitte jamais votre ordinateur : seule son empreinte est vérifiée. Ouvrez un terminal dans le dossier du fichier, puis tapez :

    Windows
    certutil -hashfile fichier.pdf SHA256
    macOS
    shasum -a 256 fichier.pdf
    Linux
    sha256sum fichier.pdf

    – adresses IP

    Chaque matin, SecureShip télécharge les indicateurs des sept derniers jours publiés par ThreatFox, une base gratuite de l'organisation suisse abuse.ch alimentée par des chercheurs en sécurité. Chaque entrée est vérifiée avant d'être ajoutée, et les grands services légitimes sont exclus pour éviter les fausses alertes.

    Quelques entrées de démonstration, sans danger, sont toujours présentes pour tester l'outil : elles utilisent des adresses réservées à la documentation et le fichier de test antivirus EICAR.

    Pour les développeurs et les analystes

    Tout ce que fait cette page passe par une API REST publique, documentée et testable dans le navigateur : ouvrir la documentation interactive.

    # Un indicateur, type détecté automatiquement
curl "/api/v1/check?q=hxxp://evil[.]example"

# Jusqu'à 100 indicateurs d'un coup
curl -X POST "/api/v1/check/bulk" \
  -H "Content-Type: application/json" \
  -d '{"indicators": ["192.0.2.10", "utt.fr"]}'

    Questions fréquentes

    Mes recherches sont-elles enregistrées ?

    Non. Les éléments que vous vérifiez ne sont ni stockés ni envoyés à un autre service. La base de menaces est chargée sur le serveur, et la comparaison se fait localement.

    « Rien trouvé » veut-il dire que c'est sans danger ?

    Non. Cela veut dire qu'aucun signalement n'est connu. Les attaquants créent de nouveaux sites chaque jour. Méfiez-vous d'un message qui vous presse, promet un gain ou demande un mot de passe.

    J'ai cliqué sur un lien signalé. Que faire ?

    Si vous avez saisi un mot de passe, changez-le immédiatement sur le vrai site et activez la double authentification. Lancez une analyse antivirus. Sur un appareil professionnel, prévenez votre service informatique. En France, cybermalveillance.gouv.fr propose une aide gratuite.

    Pourquoi un site réputé est-il parfois signalé ?

    Des pirates hébergent parfois leurs fichiers sur des services légitimes. SecureShip exclut les plus grands pour limiter les fausses alertes, mais un signalement reste possible. Le détail du résultat indique la menace et le niveau de confiance.
